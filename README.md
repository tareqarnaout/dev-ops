# DevOps

Welcome to DevOps at Princess Sumaya University for Technology.

This course introduces the core ideas and practical workflow of modern DevOps, with a strong focus on containerization and hands-on tooling. You will learn how to move from code to runnable services using Docker fundamentals, Dockerfiles, images, containers, and command-line workflows.

## What You Will Learn

- DevOps mindset and lifecycle fundamentals.
- Containerization concepts and why they matter in software delivery.
- Docker architecture and the relationship between images and containers.
- Writing and optimizing Dockerfiles.
- Day-to-day Docker CLI workflows for building, running, and debugging containers.
- Practical implementation patterns used in real-world development environments.
